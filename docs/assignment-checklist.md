## Required deliverables

### Upload 1: video

- [ ] 15-25 minutes total
- [ ] Screen is recorded
- [ ] Voice is clearly understandable
- [ ] Gameplay and mechanics are shown first
- [ ] Gameplay section is no longer than 7 minutes
- [ ] The second part explains the important Unity setup and C# implementation
- [ ] A short audio/screen test is recorded and played back immediately before the real recording
- [ ] Upload the video/ZIP directly, or provide a stable accessible link in a `.txt` file
- [ ] Link access is tested in a private/incognito browser window

### Upload 2: Unity project

- [ ] Project opens with Unity `6000.3.6f1`
- [ ] Project compiles with no project errors
- [ ] Main gameplay loop is playable from a clean open
- [ ] Only licensed/redistributable assets are included
- [ ] `Library` is excluded before creating the ZIP
- [ ] Upload the ZIP directly, or provide a stable accessible download link in a `.txt` file
- [ ] The final ZIP/link is downloaded once and tested

## Scope constraints

- Build a small game with one or two core functions.
- Target roughly 40 hours total, including the video.
- Do not exceed 50 hours unless consciously choosing to go beyond the assignment recommendation.
- Prioritize understandable mechanics and implementation over content volume.
- Models are not graded, but a completely unstyled primitive-only presentation can lose aesthetic points.
- Audio is optional.

## Grading priorities

Top priority:

- Clear explanation that demonstrates understanding

High priority:

- Game features and mechanics
- Unity implementation: Inspector, prefabs, scene setup, and Unity features
- C# implementation
- Structure: code, folders, and scene hierarchy

These top/high-priority areas account for about two-thirds of the 65 regular points.

The remaining third considers:

- Originality
- Complexity
- Aesthetics
- Unity features

## Optional bonus

- [ ] Up to +5: procedural generation
- [ ] Up to +10: VR project

For procedural visuals or shaders, parameters must be controlled through the game's code/architecture rather than being a static visual effect.

## Submission-day check

- [ ] Known limitations are documented and can be explained honestly
- [ ] No secrets, personal paths, temporary captures, or agent files are included
- [ ] Video duration is checked
- [ ] Gameplay portion is at most 7 minutes
- [ ] Both uploads are accessible
- [ ] Backup copies of the project ZIP and video are kept
